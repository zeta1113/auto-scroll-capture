# 스크롤 자동 캡처 (Scroll Auto Capture)

Windows 11에서 **스크롤되는 영역의 전체 내용**을 자동으로 스크롤하며 캡처해
한 장의 PNG로 저장하는 유틸리티입니다.
브라우저뿐 아니라 **Claude 데스크탑의 Fin AI 대화창** 같은 네이티브 앱의
긴 대화 내용도 통째로 캡처할 수 있습니다.

---

## 주요 기능

- 🧰 **7가지 캡처 버튼** (아이콘 + 툴팁, 한 줄 정렬) — 스크롤 캡처 3종 + 즉시 캡처 4종
  - **스크롤 캡처(디스플레이/윈도우/영역)** — 대상을 자동 스크롤하며 전체를 캡처(아이콘의 파란 ↓)
  - **즉시 캡처(전체 디스플레이/디스플레이/윈도우/영역)** — 스크롤 없이 현재 화면을 한 번에 캡처
  - 각 아이콘 아래에 **툴팁**(굵은 제목 + 사용 안내) 표시
- 🔄 **자동 스크롤 + 이어붙이기** — 맨 위로 이동 후 끝까지 스크롤하며 캡처
- 🧩 **겹침 자동 정합** — OpenCV 템플릿 매칭으로 중복 없이 합성
- 🧱 **적응형 스크롤** — 마우스 휠 → WM_MOUSEWHEEL 메시지 → PageDown 자동 전환
- 📌 **고정 요소 자동 제거**
  - 상단 고정 헤더 / 하단 고정 바: 자동 감지 → 맨 위 1회만 남김
  - **좌/우 고정 메뉴(사이드바) · 스크롤바**: 자동 감지 → 첫 화면만 남기고
    이후는 메뉴 배경색으로 채움. 또한 매칭에서 제외해 **정렬 정확도 향상**(틀어짐 방지)
  - 떠 있는 '위로가기' 버튼 등: 다음 컷으로 덮어써 중복 제거
- ⚙️ **옵션**
  - 최상위 자동 스크롤 후 캡처(끄면 현재 위치부터)
  - 멀티 모니터 지원(끄면 주 모니터만)
  - 캡처 프로그램 숨기기(끄면 창을 띄운 채 **진행률(%) 바** 표시)
  - 스크롤 속도 슬라이더(0.5x ~ 3x, 초기화 버튼)
  - 언어 선택(영어/한국어/일본어/중국어) — 즉시 반영, 재시작 불필요
  - **단축키 매핑** — 7종 캡처에 전역 단축키 지정(기본 Alt+Shift+1~7). 창이 숨겨져 있어도 실행
  - **캡처 후 클립보드에 자동 복사**(기본 켜짐) — 저장과 동시에 이미지가 클립보드에 복사됨
  - **높이 분할 자르기** — 캡처 결과를 지정 높이(px)마다 잘라 여러 PNG로 저장(순번 `_01, _02…`)
  - **옵션 더보기/숨기기** — 옵션 영역을 접어 파일 목록 공간을 넓힘
- 🖼 **파일 목록(썸네일)** — 캡처 결과를 프로그램 안에서 바로 확인 / 열기 / **클립보드 복사**
- 🔄 **자동 업데이트 확인** — GitHub 릴리즈를 주기적으로 확인해 새 버전 알림(설정 시)
- 💾 **설정 자동 저장** — 옵션·언어·저장 폴더를 기억(`%APPDATA%\ScrollCapture\settings.json`)

## 코드 서명 / 신뢰 인증 (Windows 보안 경고 완화)

빌드 시 자체 서명 인증서(`CN=ScrollCapture`)로 exe와 설치 파일에 **코드 서명 + 타임스탬프**가 자동 적용됩니다.
자체 서명이라 처음엔 "알 수 없는 게시자"로 보일 수 있는데, 이 PC에서 **신뢰할 수 있는 게시자**로 인식시키려면
최초 1회만 아래를 실행하세요(관리자 승인 1회):

```
trust_cert.bat   (더블클릭 → UAC에서 [예])
```

실행하면 인증서가 **신뢰할 수 있는 루트 인증 기관 / 게시자** 저장소에 등록되어,
이후 서명이 "유효(Valid)"로 표시되고 SmartScreen·보안 경고가 줄어듭니다.

> 참고
> - 이 캡처 프로그램은 캡처 자체에 네트워크를 쓰지 않습니다(방화벽 경고 없음).
>   자동 업데이트 확인을 켠 경우에만 GitHub API로 버전 정보를 읽습니다(읽기 전용).
> - 다른 PC에서도 전 세계적으로 경고 없이 배포하려면, 자체 서명이 아니라
>   공인 인증기관(CA)의 **정식 코드서명 인증서(EV)**가 필요합니다(유료).

## GitHub 자동 업데이트 확인

GitHub 릴리즈에 새 버전이 올라오면 프로그램이 **자동으로 감지해 알림**을 띄웁니다.

**동작 방식**
- 시작 시 + 이후 **6시간마다** GitHub Releases API(`.../releases/latest`)를 조회
- 최신 릴리즈 태그(`v1.3.0` 등)가 현재 버전보다 높으면 상단에 알림 배너 + **[다운로드]** 버튼 표시
- [다운로드]를 누르면 릴리즈에 첨부된 설치 파일(`.exe`)이나 릴리즈 페이지를 브라우저로 엽니다
- 언제든 옵션의 **[업데이트 확인]** 버튼으로 수동 확인 가능

**설정 방법 (배포자)**
1. GitHub에 저장소를 만들고 소스를 올립니다.
2. `source/version.py`에서 저장소를 지정합니다:
   ```python
   GITHUB_REPO = "사용자명/저장소명"   # 예: "zeta1113/scroll-capture"
   ```
   (비워두면 업데이트 기능은 비활성 — 관련 UI도 숨김)
3. 새 버전을 낼 때: `build.bat`으로 빌드 → GitHub에서 **Release 생성**
   - 태그를 **`v{버전}`** 형식으로(예: `v1.3.0`, `version.py` 버전과 일치)
   - 릴리즈에 `release/ScrollCapture_Setup_v1.3.0.exe`를 **첨부(asset)**
4. 사용자의 프로그램이 다음 확인 주기에 새 버전을 감지해 알림을 띄웁니다.

> 저장소 생성·업로드·릴리즈 발행은 GitHub 계정 권한이 필요해 사용자가 직접 진행합니다.
> `git`/`gh` CLI 또는 GitHub 웹에서 Release를 만들면 됩니다.

## 사용 방법

### A. 배포본(exe) 실행
1. `release/` 폴더의 최신 `ScrollCapture_Setup_v*.exe` 실행
   (설치 후 시작 메뉴/바탕화면 아이콘으로 실행)
2. 캡처 버튼은 7개(아이콘 + 툴팁, 한 줄). 아이콘에 마우스를 올리면 아래에 설명이 뜹니다.
   **스크롤 캡처(파란 ↓)** — 대상을 자동 스크롤하며 전체를 캡처
   - **스크롤 캡처(디스플레이)** — 모니터를 선택해 전체를 스크롤 캡처
   - **스크롤 캡처(윈도우)** — 창을 선택해(마우스로 창 위 클릭) 전체를 스크롤 캡처
   - **스크롤 캡처(영역 지정)** — 드래그로 스크롤 영역만 선택해 캡처

   **즉시 캡처** — 스크롤 없이 현재 화면을 한 번에 캡처
   - **전체 디스플레이 캡처** — 모든 모니터의 현재 화면을 한 장으로
   - **디스플레이 캡처** — 선택한 모니터의 현재 화면
   - **윈도우 캡처** — 선택한 창의 현재 화면
   - **영역 지정 캡처** — 드래그한 영역의 현재 화면

   - *모니터 선택*: 마우스가 올라간 모니터가 반투명해지고 **클릭**하면 그 모니터를 캡처.
     *창 선택*: 마우스 아래 창이 빨간 테두리로 강조되고 **클릭**하면 그 창을 캡처.
3. (스크롤 캡처) 자동으로 맨 위로 이동 → 끝까지 스크롤하며 캡처 → 한 장으로 합성
4. 완료되면 아래 **캡처한 파일** 목록에 썸네일로 표시
   - 각 항목의 **[열기]** / **[복사]**(클립보드로 이미지 복사) 버튼 사용

### 옵션
- **최상위 위치로 자동 스크롤 후 캡처**(기본 켜짐): 끄면 현재 화면 위치부터 캡처
- **멀티 모니터 지원**(기본 켜짐): 켜면 영역 선택이 전체 모니터에 걸쳐 가능,
  전체 영역 캡처 시 모니터 선택 화면 표시. 끄면 주 모니터만.
- **캡처 프로그램 숨기기**(기본 켜짐): 캡처 중 창을 숨깁니다.
  끄면 창이 그대로 보이고, 캡처 버튼 아래에 **진행률(%) 바**가 표시됩니다
  (스크롤바가 있으면 스크롤 위치 기반 실제 %, 없으면 완만히 상승 후 완료 시 100%).
  (끈 경우, 캡처할 화면 영역을 프로그램 창이 가리지 않도록 창을 옆으로 옮겨두세요.)
- **스크롤 속도**: 0.5x ~ 3x 슬라이더(+초기화). 빠를수록 캡처가 빠르지만
  내용이 복잡하면 낮추는 게 안전합니다.
- **언어**: 영어/한국어/일본어/중국어. 선택 즉시 모든 문구가 바뀝니다(재시작 불필요).

## 컴파일(빌드) 방법

### 준비물
- Python 3.11+
- **Inno Setup 6** — 정식 설치 파일(Setup.exe) 생성용
  - 설치: `winget install --id JRSoftware.InnoSetup -e`  (또는 https://jrsoftware.org/isdl.php )
  - 없으면 포터블 exe만 생성됩니다.
- 코드 서명은 Windows 기본 PowerShell(`New-SelfSignedCertificate`, `Set-AuthenticodeSignature`)로 처리되어
  별도 설치가 필요 없습니다.

### 빌드
```bat
build.bat                REM 더블클릭 또는 실행 (patch 버전 자동 증가)
```
또는
```bat
python build.py          REM patch 증가 (1.0.0 -> 1.0.1)
python build.py --minor  REM minor 증가 (1.0.1 -> 1.1.0)
python build.py --major  REM major 증가 (1.1.0 -> 2.0.0)
python build.py --no-bump  REM 버전 유지하고 재빌드
```

빌드 과정
1. `source/version.py`의 버전을 자동 증가
2. 아이콘/서명 인증서 준비(없으면 자동 생성)
3. PyInstaller로 단일 실행 파일(`ScrollCapture.exe`) 생성 + **코드 서명**
4. Inno Setup이 있으면 `release/ScrollCapture_Setup_v{버전}.exe`,
   없으면 `release/ScrollCapture_Portable_v{버전}.exe` 생성 + **코드 서명**
5. `release/RELEASES.md`에 릴리즈 기록 추가

빌드 후 최초 1회 `trust_cert.bat`을 실행하면 서명이 신뢰됨(위 "코드 서명" 참고).

## 동작 원리(요약)

- 선택 영역을 화면에서 캡처 → 매 스크롤 후 이전 프레임과 겹치는 부분을
  키 큰 템플릿 매칭(탐색 범위 제한)으로 찾아 **새 부분만** 정확히 합성.
- 반복되는 UI(구분선/버튼)나 단색 구간에도 오정합되지 않도록 설계.
- 이어붙이기가 아니라 **올바른 위치에 덮어쓰기(composite)** 방식이라
  화면에 떠 있는 고정 버튼이 다음 컷으로 자연스럽게 가려집니다.

## 주의 / 한계

- 캡처 중 대상 영역이 **다른 창에 가려지면 안 됩니다**(화면에 보이는 픽셀을 캡처).
- **세로 스크롤**만 지원합니다.
- 대상 앱이 관리자 권한으로 실행 중이면, 이 프로그램도 **관리자 권한**으로 실행해야
  스크롤/포커스 입력이 전달됩니다.
- 멀티 모니터 지원을 끄면 영역 선택은 **주 모니터** 기준입니다.
  (모니터마다 배율(DPI)이 다르면 오버레이 표시가 약간 어긋날 수 있으나,
  실제 캡처 좌표는 커서 위치 기준이라 결과는 정확합니다.)
- 헤더에 시계처럼 계속 바뀌는 요소가 있으면 고정 헤더 감지가 안 될 수 있습니다.

## 캡처 속도 조정

스크롤 속도는 프로그램의 **스크롤 속도 슬라이더**(0.5x ~ 3x)로 조정합니다.
속도가 높을수록 한 번에 더 많이 스크롤하고 대기 시간이 짧아져 빨라지지만,
내용이 복잡하거나 렌더링이 느린 앱에서는 겹침/누락이 생길 수 있으니 낮추세요.
문제가 있으면 **1x 이하**를 권장합니다.
